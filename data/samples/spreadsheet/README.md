# Sample partner spreadsheet

`county_food_pantries.csv` is a **fictional** county food pantry list, used for the
"Add a partner" demo. Phone numbers use the reserved 555-01xx range and websites use the
reserved `.example` domain.

It is deliberately messy, like real partner spreadsheets:

- Unusual headers (`Pantry Name`, `Run By`, `Phone #`, `Web`).
- A packed `Info` column holding hours, languages, eligibility and sometimes an email, as
  `Key: value | Key: value`.
- Phones in five formats: `(707) 555-0101`, `707.555.0102`, `7075550103`,
  `707-555-0104 ext 2`, `+1 707 555 0105`. One row says `call the church office`.
- One row (Vacaville Mobile Pantry) has no street address.
- A website without `https://`, and some rows with no website.
